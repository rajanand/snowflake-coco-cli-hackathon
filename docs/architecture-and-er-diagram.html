Medallion architecture

Five fragmented source systems land into a unified BRONZE layer, are resolved into one canonical SILVER layer (entity resolution + governance-approved metric definitions), modeled dimensionally in GOLD, exposed as a governed SEMANTIC_MODELS layer, and operationalized via AUTOMATION. Consumption happens through a hybrid agent router, Streamlit, and (stretch) Snowsight / Slack.

Grain reference

EntityGrain
Supplierone row per supplier (SCD2)
Partone row per SKU
Plantone row per facility
Customerone row per customer
Shipmentone row per delivery
Invoiceone row per cost document (0-or-1 per shipment — the Landed Cost gap)
CustomerOrderone row per order line
Inventory (snapshot)one row per part-plant-day
QualityEventone row per defect
