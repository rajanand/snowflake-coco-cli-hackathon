Medallion architecture (as built)

Five fragmented source systems land into a unified BRONZE layer, are resolved into one canonical SILVER layer (entity resolution via shipment_crosswalk + governance-approved metric definitions), modeled dimensionally in GOLD (28 Dynamic Tables), and exposed as a governed SEMANTIC_MODELS layer — a native SEMANTIC VIEW plus Cortex Search over supplier contract PDFs. A multi-agent router and two deployed Streamlit apps consume only that governed layer, never the raw source tables. RBAC, Marketplace enrichment, and a Workspace artifact round out governance and ops.

Built Phases 0-5, 7, Governance & Ops — recorded execution evidence in each sql/ phase README Deferred AUTOMATION (Tasks/alerting) and a packaged CoCo skill — explicit decision, not oversight (docs/pending-gaps.md)

Entity-relationship diagram (deployed Semantic View)

Nine business entities exactly as declared in the live CREATE SEMANTIC VIEW SUPPLY_CHAIN_ONTOLOGY object — not the pre-build plan's entity list. bridge_supplier_part and fact_quality_event exist as Gold Dynamic Tables but are deliberately not exposed through the semantic view, so they're omitted here too. Shipment ↔ LandedCost is the one 1-to-1 relationship — every other link below is one dimension to many facts.
